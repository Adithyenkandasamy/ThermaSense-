Design a premium, futuristic web application dashboard UI for a project called "ThermaSense" — a Geospatial Thermal Anomaly Intelligence Platform.

The application analyzes satellite-detected thermal anomalies and helps investigate what they may actually represent, such as Wildfire, Vegetation Fire, Agricultural Burning, Industrial Heat, Gas Flaring, Volcanic Activity, Other Thermal Source, or Unknown.

IMPORTANT:
This is NOT just a wildfire monitoring dashboard. The central purpose is thermal anomaly attribution and explainable intelligence.

VISUAL STYLE:
Create a cinematic, sophisticated geospatial intelligence interface inspired by a modern satellite mission control center, environmental intelligence platform, and advanced AI analytics dashboard.

Use the uploaded reference image ONLY as visual inspiration for layout quality, atmospheric depth, glass panels, typography hierarchy, and dashboard composition. Do not copy its exact design.
